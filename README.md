# Fazazero (КЗ-Эксперт)

> **Пакетный генератор томов расчета петли «фаза-ноль» по ГОСТ 28249-93 и ПУЭ-7 для государственной экспертизы.**

## Архитектура
- **100% Client-Side (Zero-Server SaaS):** все вычисления, парсинг Excel и верстка документов Word выполняются локально в оперативной памяти браузера.
- **Безопасность данных (Air-Gap):** коммерческая и государственная тайна защищены — данные кабельных сетей объектов не передаются в сеть.
- **Статус 152-ФЗ:** Персональные данные = 0. Сервер отсутствует, баз данных нет.
- **Юридический статус:** Самозанятость (НПД).

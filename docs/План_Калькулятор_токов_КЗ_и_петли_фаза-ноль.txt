2. МАТЕМАТИЧЕСКАЯ И ИНЖЕНЕРНАЯ МОДЕЛЬ (РЕАЛИСТИЧНЫЙ ГОСТ 28249-93)
================================================================================

В отличие от примитивных калькуляторов «одного провода», математическое ядро
полностью отражает структуру реальных распределительных сетей 0.4 кВ.

2.1. ГИБКИЙ ВЫБОР ИСТОЧНИКА ПИТАНИЯ (ТУМБЛЕР ИСТОЧНИКА):
Программа поддерживает 2 взаимоисключающих режима задания головного узла:
- РЕЖИМ А (Внешние сети, раздел ЭС): Расчет от питающего силового трансформатора ТП.
  * Вход: Мощность S_ном (63–2500 кВА), схема обмоток (Y/Yн-0 или D/Yн-11), u_к (%), P_к (кВт).
  * Прямая последовательность: Z_т, R_т, X_т = sqrt(Z_т^2 - R_т^2).
  * Нулевая последовательность: для D/Yн Z_т(0) ≈ Z_т; для Y/Yн Z_т(0) берется
    из нормативной таблицы ГОСТ 28249-93 (приложение 3) с учетом потоков рассеяния.
- РЕЖИМ Б (Внутренние сети, раздел ЭОМ): Расчет от вводных клемм ВРУ здания по ТУ.
  * Проектировщик внутрянки не знает параметров ТП. Он вводит данные из ТУ сетевой
    организации: ток 3-фазного КЗ на шинах ВРУ (I_кз(3)) или мощность КЗ (S_кз).
  * Эквивалентное комплексное сопротивление системы до шин ВРУ рассчитывается автоматически:
    Z_сист = (c * U_ном) / (sqrt(3) * I_кз(3)).

2.2. КАСКАДНЫЙ РАСЧЕТ МНОГОЗВЕННОЙ КАБЕЛЬНОЙ ЦЕПИ (ДО 5 УЧАСТКОВ):
Реальная цепь состоит из последовательных звеньев:
[ТП] ➔ [1. Кабель в траншее] ➔ [ВРУ] ➔ [2. Стояк] ➔ [ЩЭ] ➔ [3. Групповая линия] ➔ [Розетка].
Для каждого звена цепи раздельно учитываются:
- Длина участка L_i (м), материал (медь / алюминий), сечение фазной и нулевой жил (S_ф, S_0).
- Температура нагрева жил при нормальной нагрузке (+65 °C по ГОСТ, а не +20 °C!):
  R_жил = (rho_20 * [1 + alpha * (65 - 20)] * L_i) / S
- Индуктивное погонное сопротивление линии x_0 (Ом/км) с учетом способа прокладки.

2.3. ПЕРЕХОДНЫЕ СОПРОТИВЛЕНИЯ И СОПРОТИВЛЕНИЕ ЭЛЕКТРИЧЕСКОЙ ДУГИ:
По ГОСТ 28249-93 (табл. 1 и разд. 3) в контур петли включаются:
- Сопротивления контактных соединений и аппаратов коммутации (R_конт ≈ 0.015...0.03 Ом).
- Сопротивление дуги в точке КЗ (для вычисления минимального расчетного тока КЗ):
  R_дуги определяется расчетным путем в зависимости от ожидаемого тока.

2.4. ИТОГОВОЕ СОПРОТИВЛЕНИЕ ПЕТЛИ ФАЗА-НОЛЬ И ТОК КЗ:
- Суммарное активное сопротивление цепи: R_сум = R_ист(0)/3 + sum(R_ф_i + R_0_i) + R_конт + R_дуги
- Суммарное индуктивное сопротивление:   X_сум = X_ист(0)/3 + sum(X_ф_i + X_0_i)
- Полное сопротивление петли фаза-ноль:  Z_п-н = sqrt(R_сум^2 + X_сум^2)
- Минимальный ток однофазного КЗ:        I_кз(1) = (c * U_ф) / Z_п-н  (где U_ф = 230 В, c = 1.0)

2.5. ПРОВЕРКА УСЛОВИЯ СРАБАТЫВАНИЯ ЗАЩИТЫ (ПУЭ-7 п. 1.7.79):
Программа поддерживает как модульные, так и силовые промышленные автоматы:
- Модульные автоматы (кривые B: 3–5 In, C: 5–10 In, D: 10–20 In).
- Силовые автоматические выключатели в литом корпусе (ВА88, ВА57, ВА55, Compact NSX,
  Tmax, CHINT NM8N) с настраиваемыми электронными/термомагнитными расцепителями
  (прямой ввод уставки электромагнитной отсечки I_sd / I_i и множителя k).
- Критерий электробезопасности:
  * Необходимый ток надежного мгновенного отключения: I_отс_треб = 1.1 * I_сраб_макс.
  * Если I_кз(1) >= I_отс_треб: СТАТУС ЗЕЛЕНЫЙ («Условие ПУЭ выполнено, t <= 0.1 с»).
  * Если I_кз(1) < I_отс_треб:  СТАТУС КРАСНЫЙ («ОТКАЗ: ток КЗ недостаточен для отсечки.
    Рекомендация: увеличить сечение нулевой жилы или заменить кривую автомата с C на B»).

3. АРХИТЕКТУРА И ТЕХНОЛОГИЧЕСКИЙ СТЕК (ZERO-SERVER / СХЕМА РУКРЕДИТЫ)
================================================================================

3.1. СТЕК ТЕХНОЛОГИЙ 100% CLIENT-SIDE:
- Язык разработки: TypeScript / современный JavaScript (ES2024).
- Для защиты интеллектуальной собственности ядра: компиляция расчетного модуля
  в WebAssembly (.wasm) на базе Rust или C++ (невозможно восстановить декомпилятором).
- Парсер файлов: Библиотека `SheetJS` (`xlsx.js`) — читает Excel-файлы в оперативной
  памяти браузера через FileReader API за доли секунды.
- Шаблонизатор и сборщик Word: Библиотеки `docx.js` / `docxtemplater` + `PizZip` —
  верстают документ Word по стандарту ГОСТ 2.105-95 в памяти вкладки с прямой
  выдачей бинарного файла через браузерный Blob (`saveAs`).
- Производительность: Использование `Web Workers` (фоновый поток браузера) — интерфейс
  не подвисает даже при расчете журнала на 1 000 кабельных линий.
- Автономность: `Service Worker` + Web App Manifest (стандарт PWA) — возможность
  установки сайта как нативного приложения для работы на закрытых объектах без интернета.

3.2. ПРОТОКОЛ ДОКАЗАТЕЛЬСТВА ZERO-SERVER ДЛЯ СЛУЖБЫ БЕЗОПАСНОСТИ (СБ):
Служба безопасности проектных институтов не верит декларациям в подвале сайта.
Сервис предоставляет 5 неопровержимых технических доказательств изоляции данных:

1. ФИЗИЧЕСКИЙ ТЕСТ «ВЫДЕРНИ ШНУР / РЕЖИМ ПОЛЁТА» (AIR-GAP TEST):
   - Инструкция для инспектора СБ прямо на главной странице:
     1) Откройте страницу сервиса в браузере.
     2) Полностью отключите компьютер от сети (выдерните кабель Ethernet или выключите Wi-Fi).
     3) Перетащите в окно браузера секретный кабельный журнал (.xlsx) и нажмите «Рассчитать».
     4) Все расчеты мгновенно выполняются, отчет формируется.
   - Вывод для СБ: Закон физики непреложен. При выключенном сетевом интерфейсе
     данные физически не могут покинуть оперативную память компьютера.

2. ЗАЩИТА НА УРОВНЕ ЯДРА БРАУЗЕРА: HTTP-ЗАГОЛОВОК CONTENT-SECURITY-POLICY (CSP):
   - Сервер статики отдает браузеру строжайший заголовок безопасности:
     `Content-Security-Policy: default-src 'self'; script-src 'self'; connect-src 'none'; style-src 'self' 'unsafe-inline';`
   - Директива `connect-src 'none'` НА УРОВНЕ ДВИЖКА БРАУЗЕРА блокирует любые сетевые
     вызовы (fetch, XMLHttpRequest, WebSocket, beacon). Браузер физически пресекает попытку утечки.
   - Инженер ИБ нажимает F12 ➔ Network ➔ Headers и лично видит действующий заголовок CSP.

3. АУДИТ ТРАФИКА ЧЕРЕЗ DEVTOOLS (F12 NETWORK = 0 БАЙТ):
   - При загрузке журнала и расчете вкладка Network (фильтр Fetch/XHR) показывает:
     `0 requests, 0 bytes transferred`. В сеть не уходит ни единого байта.

4. РЕЖИМ PWA ДЛЯ РЕЖИМНЫХ ОБЪЕКТОВ:
   - Приложение устанавливается в 1 клик на рабочий стол и работает полностью автономно
     на компьютерах закрытых контуров, не имеющих физического выхода в интернет.

5. РАЗРЫВ КОНТЕКСТА ДАННЫХ ПРИ ОПЛАТЕ:
   - В платежный шлюз банка передаются только два служебных параметра:
     `{ "amount": 990, "description": "Лицензионный доступ к формированию отчета Word" }`.
   - Чертежи, марки кабелей, длины и названия объектов не передаются в банк.

НЕДЕЛЯ 1: МАТЕМАТИЧЕСКИЙ ДВИЖОК И СПРАВОЧНИКИ ГОСТ
--------------------------------------------------------------------------------
- День 1: Формирование компактного статического JSON-справочника `database.json`
  (трансформаторы ТМ/ТМГ со схемами Y/Y0 и D/Y0, удельные сопротивления жил по ГОСТ 22483,
  параметры модульных и литых автоматов ВА47, ВА88, Acti9, Tmax).
- День 2–3: Написание чистого расчетного модуля `math_engine.ts`:
  * каскадное сложение комплексных сопротивлений прямой и нулевой последовательности;
  * учет рабочей температуры жил (+65 °C) и переходных сопротивлений дуги;
  * ветка расчета через параметры ТП и ветка через ток КЗ на шинах ВРУ.
- День 4: Автоматическое тестирование ядра (Jest/Vitest). Сверка с 10 типовыми
  примерами из справочника Шабада и типового альбома А5-92. Точность совпадения > 99%.
- День 5: Оптимизация математики под WebAssembly (Rust/Wasm) для защиты исходного кода.
- Результат недели: Готовое расчетное ядро, вычисляющее 100 линий за 1 миллисекунду.

  * вставка сводной итоговой таблицы соответствия автоматов требованиям ПУЭ-7.
- День 10: Тестирование открытия сформированных файлов в Word, МойОфис и LibreOffice.
- Результат недели: Полный цикл «Excel ➔ Расчет ➔ Готовый Word-файл» в оперативной памяти.
